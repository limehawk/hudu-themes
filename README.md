# hudu-themes

Custom CSS themes for [Hudu](https://www.hudu.com).

## Themes

| Theme | Preview | Source |
|-------|---------|--------|
| [Flexoki](themes/flexoki/) | Warm paper-tone palette by [Steph Ango](https://stephango.com/flexoki) | [theme.css](themes/flexoki/theme.css) |

## Install

1. Hudu admin → **Settings** → **Customize Branding** (or **Custom CSS**).
2. Paste the contents of the theme's `theme.css` into the custom CSS field.
3. Save.
