# Arc Blueberry theme for Hudu

Hudu skin generated from the omarchy `arc-blueberry` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [vale-c/omarchy-arc-blueberry](https://github.com/vale-c/omarchy-arc-blueberry) — listed on [omarchytheme.com](https://omarchytheme.com/themes/arc-blueberry/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `arc-blueberry` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
