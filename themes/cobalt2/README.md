# Cobalt2 theme for Hudu

Hudu skin generated from the omarchy `cobalt2` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [hoblin/omarchy-cobalt2-theme](https://github.com/hoblin/omarchy-cobalt2-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/cobalt2/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `cobalt2` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
