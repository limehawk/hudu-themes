# Krishna theme for Hudu

Hudu skin generated from the omarchy `krishna` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [tanishenigma/omarchy-krishna-theme](https://github.com/tanishenigma/omarchy-krishna-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/krishna/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `krishna` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
