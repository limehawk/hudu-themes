# Gta theme for Hudu

Hudu skin generated from the omarchy `gta` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [jordan-ops/omarchy-GTA-theme](https://github.com/jordan-ops/omarchy-GTA-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/gta/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `gta` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
