# Solarized theme for Hudu

Hudu skin generated from the omarchy `solarized` + `solarized-light` palettes via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [Gazler/omarchy-solarized-theme](https://github.com/Gazler/omarchy-solarized-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/solarized/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `solarized` theme paired with `solarized-light`
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
