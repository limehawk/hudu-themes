# Hydra Pressure theme for Hudu

Hudu skin generated from the omarchy `hydra-pressure` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [monoooki/omarchy-hydra-pressure-theme](https://github.com/monoooki/omarchy-hydra-pressure-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/hydra-pressure/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `hydra-pressure` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
