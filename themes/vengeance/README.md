# Vengeance theme for Hudu

Hudu skin generated from the omarchy `vengeance` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [Grey-007/vengeance](https://github.com/Grey-007/vengeance) — listed on [omarchytheme.com](https://omarchytheme.com/themes/vengeance/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `vengeance` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
