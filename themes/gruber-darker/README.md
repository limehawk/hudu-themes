# Gruber Darker theme for Hudu

Hudu skin generated from the omarchy `gruber-darker` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [celsobenedetti/omarchy-gruber-darker](https://github.com/celsobenedetti/omarchy-gruber-darker) — listed on [omarchytheme.com](https://omarchytheme.com/themes/gruber-darker/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `gruber-darker` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
