# Ktm 390 Enduro R theme for Hudu

Palette from [twodogsdave/KTM-390-Enduro-R](https://github.com/twodogsdave/KTM-390-Enduro-R) — listed on [omarchytheme.com](https://omarchytheme.com/themes/ktm-390-enduro-r/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `ktm-390-enduro-r` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
