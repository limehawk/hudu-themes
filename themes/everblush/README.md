# Everblush theme for Hudu

Hudu skin generated from the omarchy `everblush` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [Swarnim114/omarchy-everblush-theme](https://github.com/Swarnim114/omarchy-everblush-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/everblush/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `everblush` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
