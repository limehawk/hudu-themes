# Deadspace theme for Hudu

Hudu skin generated from the omarchy `deadspace` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [atif-1402/omarchy-deadspace-theme](https://github.com/atif-1402/omarchy-deadspace-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/deadspace/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `deadspace` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
