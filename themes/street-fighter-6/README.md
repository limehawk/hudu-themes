# Street Fighter 6 theme for Hudu

Hudu skin generated from the omarchy `street-fighter-6` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [AlxWolfenstein97/omarchy-street-fighter-6-theme](https://github.com/AlxWolfenstein97/omarchy-street-fighter-6-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/street-fighter-6/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `street-fighter-6` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
