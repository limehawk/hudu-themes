# Motivator theme for Hudu

Hudu skin generated from the omarchy `motivator` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [rondilley/omarchy-motivator-theme](https://github.com/rondilley/omarchy-motivator-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/motivator/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `motivator` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
