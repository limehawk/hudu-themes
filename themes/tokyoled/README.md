# Tokyoled theme for Hudu

Hudu skin generated from the omarchy `tokyoled` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [Justin-De-Sio/omarchy-tokyoled-theme](https://github.com/Justin-De-Sio/omarchy-tokyoled-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/tokyoled/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `tokyoled` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
