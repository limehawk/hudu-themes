# Ryu theme for Hudu

Hudu skin generated from the omarchy `ryu` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [HANCORE-linux/omarchy-ryu-theme](https://github.com/HANCORE-linux/omarchy-ryu-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/ryu/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `ryu` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
