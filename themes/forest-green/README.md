# Forest Green theme for Hudu

Hudu skin generated from the omarchy `forest-green` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [abhijeet-swami/omarchy-forest-green-theme](https://github.com/abhijeet-swami/omarchy-forest-green-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/forest-green/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `forest-green` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
