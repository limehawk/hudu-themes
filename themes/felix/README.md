# Felix theme for Hudu

Hudu skin generated from the omarchy `felix` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [TyRichards/omarchy-felix-theme](https://github.com/TyRichards/omarchy-felix-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/felix/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `felix` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
