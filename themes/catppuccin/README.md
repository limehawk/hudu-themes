# Catppuccin theme for Hudu

Hudu skin generated from the omarchy `catppuccin` + `catppuccin-latte` palettes via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette © the [Catppuccin](https://github.com/catppuccin/catppuccin) community (MIT) — soothing pastel theme; this port uses Mocha (dark) + Latte (light).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `catppuccin` theme paired with `catppuccin-latte`
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
