# Night Owl theme for Hudu

Hudu skin generated from the omarchy `night-owl` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [janhesters/omarchy-night-owl-theme](https://github.com/janhesters/omarchy-night-owl-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/night-owl/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `night-owl` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
