Palette from [atif-1402/omarchy-type17-theme](https://github.com/atif-1402/omarchy-type17-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/type17/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `type17` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
