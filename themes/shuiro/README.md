# Shuiro theme for Hudu

Hudu skin generated from the omarchy `shuiro` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [Grenish/omarchy-shuiro-theme](https://github.com/Grenish/omarchy-shuiro-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/shuiro/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `shuiro` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
