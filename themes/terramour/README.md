# Terramour theme for Hudu

Hudu skin generated from the omarchy `terramour` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [atif-1402/omarchy-terramour-theme](https://github.com/atif-1402/omarchy-terramour-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/terramour/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `terramour` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
