# Taikami theme for Hudu

Hudu skin generated from the omarchy `taikami` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [SamuelCam14/taikami](https://github.com/SamuelCam14/taikami) — listed on [omarchytheme.com](https://omarchytheme.com/themes/taikami/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `taikami` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
