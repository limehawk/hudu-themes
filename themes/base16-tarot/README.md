# Base16 Tarot theme for Hudu

Hudu skin generated from the omarchy `base16-tarot` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [jjdizz1l/base16-tarot](https://github.com/jjdizz1l/base16-tarot) — listed on [omarchytheme.com](https://omarchytheme.com/themes/base16-tarot/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `base16-tarot` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
