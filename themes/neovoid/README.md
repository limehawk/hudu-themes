# Neovoid theme for Hudu

Hudu skin generated from the omarchy `neovoid` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [RiO7MAKK3R/omarchy-neovoid-theme](https://github.com/RiO7MAKK3R/omarchy-neovoid-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/neovoid/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `neovoid` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
