# Pmndrs theme for Hudu

Hudu skin generated from the omarchy `pmndrs` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [leweyse/omarchy-pmndrs-theme](https://github.com/leweyse/omarchy-pmndrs-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/pmndrs/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `pmndrs` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
