# Aetheria theme for Hudu

Hudu skin generated from the omarchy `aetheria` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [JJDizz1L/aetheria](https://github.com/JJDizz1L/aetheria) — listed on [omarchytheme.com](https://omarchytheme.com/themes/aetheria/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `aetheria` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
