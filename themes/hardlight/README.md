# Hardlight theme for Hudu

Hudu skin generated from the omarchy `hardlight` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [randallyash/omarchy-hardlight-theme](https://github.com/randallyash/omarchy-hardlight-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/hardlight/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `hardlight` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
