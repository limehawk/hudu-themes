# Hollow Knight theme for Hudu

Hudu skin generated from the omarchy `hollow-knight` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [bjarneo/omarchy-hollow-knight-theme](https://github.com/bjarneo/omarchy-hollow-knight-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/hollow-knight/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `hollow-knight` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
