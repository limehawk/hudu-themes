# Hyprblue theme for Hudu

Hudu skin generated from the omarchy `hyprblue` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [Grey-007/hyprblue](https://github.com/Grey-007/hyprblue) — listed on [omarchytheme.com](https://omarchytheme.com/themes/hyprblue/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `hyprblue` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
