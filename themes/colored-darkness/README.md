# Colored Darkness theme for Hudu

Hudu skin generated from the omarchy `colored-darkness` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [Palccod/colored-darkness](https://github.com/Palccod/colored-darkness) — listed on [omarchytheme.com](https://omarchytheme.com/themes/colored-darkness/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `colored-darkness` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
