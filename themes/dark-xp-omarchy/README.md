# Dark Xp Omarchy theme for Hudu

Hudu skin generated from the omarchy `dark-xp-omarchy` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [ITSZXY/dark-xp-omarchy](https://github.com/ITSZXY/dark-xp-omarchy) — listed on [omarchytheme.com](https://omarchytheme.com/themes/dark-xp-omarchy/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `dark-xp-omarchy` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
