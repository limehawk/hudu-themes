# Pulsar theme for Hudu

Hudu skin generated from the omarchy `pulsar` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [bjarneo/omarchy-pulsar-theme](https://github.com/bjarneo/omarchy-pulsar-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/pulsar/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `pulsar` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
