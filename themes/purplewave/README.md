# Purplewave theme for Hudu

Hudu skin generated from the omarchy `purplewave` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [dotsilva/omarchy-purplewave-theme](https://github.com/dotsilva/omarchy-purplewave-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/purplewave/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `purplewave` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
