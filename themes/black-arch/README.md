# Black Arch theme for Hudu

Hudu skin generated from the omarchy `black-arch` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [ankur311sudo/black_arch](https://github.com/ankur311sudo/black_arch) — listed on [omarchytheme.com](https://omarchytheme.com/themes/black-arch/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `black-arch` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
