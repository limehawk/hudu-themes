# Sapphire theme for Hudu

Hudu skin generated from the omarchy `sapphire` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [HANCORE-linux/omarchy-sapphire-theme](https://github.com/HANCORE-linux/omarchy-sapphire-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/sapphire/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `sapphire` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
