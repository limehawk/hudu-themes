# Adrift theme for Hudu

Hudu skin generated from the omarchy `adrift` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [jaredb1011/omarchy-adrift-theme](https://github.com/jaredb1011/omarchy-adrift-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/adrift/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `adrift` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
