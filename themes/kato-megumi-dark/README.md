# Kato Megumi Dark theme for Hudu

Hudu skin generated from the omarchy `kato-megumi-dark` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [SoujiOkita98/omarchy-kato-megumi-dark-theme](https://github.com/SoujiOkita98/omarchy-kato-megumi-dark-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/kato-megumi-dark/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `kato-megumi-dark` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
