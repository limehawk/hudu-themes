# Snow Black theme for Hudu

Hudu skin generated from the omarchy `snow-black` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [ankur311sudo/snow_black](https://github.com/ankur311sudo/snow_black) — listed on [omarchytheme.com](https://omarchytheme.com/themes/snow-black/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `snow-black` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
