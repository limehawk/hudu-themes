# Flexoki theme for Hudu

Hudu skin using the [Flexoki](https://stephango.com/flexoki) palette by Steph Ango — warm paper tones, ink-black text, muted accent colors. Light + dark mode.

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (admin → Settings → Customize Branding).
