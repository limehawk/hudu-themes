# Awakening theme for Hudu

Hudu skin generated from the omarchy `awakening` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [OldJobobo/omarchy-awakening-theme](https://github.com/OldJobobo/omarchy-awakening-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/awakening/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `awakening` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
