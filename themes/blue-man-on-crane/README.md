# Blue Man On Crane theme for Hudu

Hudu skin generated from the omarchy `blue-man-on-crane` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [twodogsdave/omarchy-blue-man-on-crane-theme](https://github.com/twodogsdave/omarchy-blue-man-on-crane-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/blue-man-on-crane/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `blue-man-on-crane` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
