# Catppuccin Glass theme for Hudu

Hudu skin generated from the omarchy `catppuccin-glass` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette from [Luquatic/omarchy-catppuccin-glass](https://github.com/Luquatic/omarchy-catppuccin-glass) — listed on [omarchytheme.com](https://omarchytheme.com/themes/catppuccin-glass/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port.py`](../../tools/omarchy-port/port.py) from the omarchy `catppuccin-glass` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
