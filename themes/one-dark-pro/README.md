# One Dark Pro theme for Hudu

Hudu skin generated from the omarchy `one-dark-pro` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [sc0ttman/omarchy-one-dark-pro-theme](https://github.com/sc0ttman/omarchy-one-dark-pro-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/one-dark-pro/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `one-dark-pro` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
