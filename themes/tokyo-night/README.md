# Tokyo Night theme for Hudu

Hudu skin generated from the omarchy `tokyo-night` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme) by enkia (also [folke/tokyonight.nvim](https://github.com/folke/tokyonight.nvim)) — neon-on-dark inspired by Tokyo at night.

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `tokyo-night` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
