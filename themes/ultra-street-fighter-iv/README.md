Hudu skin generated from the omarchy `ultra-street-fighter-iv` palette (light half synthesized) via [`tools/omarchy-to-hudu`](../../tools/omarchy-to-hudu/). Light + dark mode.

Palette from [AlxWolfenstein97/omarchy-ultra-street-fighter-iv-theme](https://github.com/AlxWolfenstein97/omarchy-ultra-street-fighter-iv-theme) — listed on [omarchytheme.com](https://omarchytheme.com/themes/ultra-street-fighter-iv/).

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-to-hudu/port_theme.py) from the omarchy `ultra-street-fighter-iv` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
