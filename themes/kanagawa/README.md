# Kanagawa theme for Hudu

Hudu skin generated from the omarchy `kanagawa` palette (light half synthesized) via [`tools/omarchy-port`](../../tools/omarchy-port/). Light + dark mode.

Palette © [rebelot/kanagawa.nvim](https://github.com/rebelot/kanagawa.nvim) (MIT) — inspired by Katsushika Hokusai's The Great Wave.

## Install

Paste [`theme.css`](theme.css) into Hudu's custom CSS field (Admin → Design → Custom CSS), save, hard-refresh.

## Source

- Generated by [`port_theme.py`](../../tools/omarchy-port/port_theme.py) from the omarchy `kanagawa` theme (no light variant — light half synthesized)
- Structure and hand-tuned Hudu fixes inherited from the [Flexoki theme](../flexoki/)
